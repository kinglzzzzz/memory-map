# 拾光 Agent 知识库架构

本模块参考了 GitHub 上 Dify、RAGFlow 与 LangChain 的公开架构思路，并针对当前项目规模实现为轻量、可本地运行的检索增强问答。

## 数据分层

- `app_user`：保留原职责，只存放账号及密码哈希。
- `memories`：保留原职责，存放用户自己的地点、照片和心情记录。
- `knowledge_entries`：公共主题知识条目，包含分类、关键词、正文、行动步骤和来源。
- `agent_messages`：按 `user_id` 保存用户与 Agent 的对话及知识来源。

## 请求流程

1. 浏览器向 `POST /api/agent/query` 发送问题。
2. 服务端读取启用的知识条目，并以标题、分类、关键词和中文相邻字符进行相关度排序。
3. 服务端只读取当前会话用户的 `memories`，生成个人上下文。
4. 回答返回正文、引用条目、匹配数量和参与回答的记忆数量。
5. 问题和回答写入 `agent_messages`，刷新页面后可恢复最近会话。

当前实现不依赖外部大模型或向量数据库，适合课程项目和本地部署。以后可以在不改变前端 API 的前提下，将检索函数替换为向量检索或外部模型生成。
